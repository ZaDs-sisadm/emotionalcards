# Що реалізовано
Чисті компоненти і сторінки: StartPage, GamePage, ResultsPage.

Кастомні хуки з логікою:

useGame — генерація карток, відкриття карт, перевірка пар, лічильник ходів, рестарт.

useTimer — таймер з можливістю запуску/скидання.

useResults — збереження останнього результату (локально в стані хука; можна розширити на localStorage або Context).

UI-компоненти: Button, Logo, IconPlaceholder, Container, Header, EmojiCard, Grid, Timer/Moves placeholders.

Базові стилі: variables.css, global.css..

Перемикання між сторінками через стан App (без react-router).

# Що не реалізовано

Серверна частина і зберігання результатів на бекенді.

Постійне збереження результатів між сесіями (за замовчуванням useResults зберігає у пам’яті).

Просунута валідація/доступність і розширені тести.

Підтримка розширених налаштувань рівнів (можна легко розширити).

# Запуск локально

Клонувати репозиторій:

git clone <посиланнянарепо>

Інсталювати залежності:

npm install

Запустити dev-сервер:

npm run dev або npm start

Відкрити в браузері:

http://localhost:3000 (або адресу, яку виведе збірник)

Корисні команди:

Перевірка TypeScript: npx tsc --noEmit

Перезапуск TS сервера у VS Code: Command Palette → TypeScript: Restart TS Server
